Study Hours and Academic Performance Analysis

Project Overview

This project investigates the relationship between the number of hours students spend studying each day and their Cumulative Grade Point Average (CGPA).

Research Question

Does the amount of time a student spends studying each day affect their academic performance?

Project Objectives

- Explore the relationship between daily study hours and CGPA.
- Summarize academic performance across different study-hour groups.
- Present findings using tables, calculations, and visualizations.

Dataset

The dataset contains information about students' daily study hours and CGPA.

Source: Kaggle — Study Hours Impact on CGPA

Tools

- GitHub — project documentation and version control
- Spreadsheet software — data exploration and calculations
- Data visualization — presenting findings clearly

Analysis

This project uses descriptive analysis to summarize study hours and compare average CGPA across study-hour groups.

Key Findings

The initial analysis suggests that students who studied longer tended to have higher average CGPA in this dataset.

This is an association in the observed data and does not prove that longer study hours alone cause higher academic performance.

Conclusion

This project demonstrates how data can be used to investigate a question, summarize results, and communicate findings.

Future Improvements

- Investigate attendance and previous academic performance if suitable data becomes available.
- Create additional visualizations.
- Explore the limitations of the dataset.
